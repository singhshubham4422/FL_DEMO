# Federated Smart Grid Simulator

This is a Next.js (App Router) demo app showcasing a federated learning smart grid simulator with animated network visualization, charts, and privacy features (DP & SMPC).

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes:
- Uses Tailwind CSS, Framer Motion, and Recharts.
- Start the simulation from the Dashboard to see animated charts and network visualization.
